# LearnLoop project instructions

For learning requests in this project, read and follow
`learnloop/SKILL.md`. Use the active conversation as the source unless the
user explicitly provides an imported transcript. Route requests to the skill's
teach, capture, reality, practice, review, and job-description workflows.

For Notion writes, use the IDs in `learnloop/config.local.json` if it
exists, otherwise find the `LearnLoop` page in Notion as the skill
describes; never expose those IDs in a public artifact.
If Notion is unavailable, provide the complete note locally and say it was not
saved to Notion.
