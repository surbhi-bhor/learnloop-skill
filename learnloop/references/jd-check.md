# Job-description gap check

Read this reference when the user asks to compare a job description with their
learning or experience. Use the actual supplied description as evidence; do
not generalize from the job title alone.

## Map requirements

1. Identify the target role and seniority from the job description. If unclear,
   use the Profile target or ask one focused question.
2. Extract distinct requirements and preserve short phrases that explain why a
   skill is required. Do not copy the entire description into Notion.
3. Match each requirement against the Learning Log, Reality Cards, applied
   topics, completed projects, and confirmed Evidence Ledger rows.
4. Label each requirement **Covered**, **Partial**, or **Gap**. A study note
   alone is not proof of practical application. Use confirmed practice,
   project, or evidence records to support Applied status.
5. Identify the next few useful learning topics or projects, prioritizing
   required skills with no evidence and weak spots relevant to the role.
6. Update Skill Map rows with the role, requirement phrase, coverage level,
   linked Learning Log topic, and source/date. Keep the learner's self-rated
   level separate from job requirement importance.

## Reporting

Show the requirement, matched evidence, coverage label, and the next action.
Quote only short phrases. Distinguish a missing record from evidence that the
learner lacks a skill: a blank map means **not yet evidenced**, not proven
inability. Mark uncertain mappings and avoid false precision in match scores.
