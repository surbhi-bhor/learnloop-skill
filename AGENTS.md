# LearnLoop project instructions

When the user asks to learn or understand a topic, explain it in a style, connect it to real work, create practice, review a topic, check a job description, or save learning from the current conversation, use `learnloop/SKILL.md` before any Notion search or write. This includes requests to quiz, make flashcards, log or capture learning, or ask what the user struggled with.

Treat the current conversation as the source by default; do not require an export of the active chat. Use the conversation context to identify the topic and include the actual teaching content in the study note. Ask about an ambiguous topic or flagged struggle before recording it. For an imported chat, follow the skill's transcript-file path. If Notion tools are unavailable, make the note locally and tell the user that it has not been written to Notion.

Notion access comes from this tool's own Notion MCP connection, not from Claude's connector. If no Notion tools are listed in this session, say so and point the user to connecting the official Notion MCP server for this tool before writing anything.
